# KolAman
## הוראות הרצה
וודא שהנך נמצא בתיקיית הפרוייקט
```
cd NotificationGate
```
```
docker compose up --build -d
```
```
docker ps
```
וודא שקפקא עלה

כנס לתיקיית alert-simulator

הפעל את הסקריפט בלחיצה כפולה על הקובץ run.bat

תוודא שההתראות נשלחות בטרמינל נפרד
```
dotnet run
```
יודפסו לך הנתיבים

ההתראות נשלחות לקפקא!
